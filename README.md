# JKKS Industries – Rice Applicator Website

Patent-pending Rice Applicator for electric vehicle lithium-ion battery fires.

**Single firefighter deployment • Up to 600 GPM • 100% USA made**

## Files

- `index.html` – Full single-page website
- Images needed in the same directory:
  - `logo.webp` – JKKS Industries logo
  - `product.jpg` – Rice Applicator product photo
  - `hero.jpg` – Hero background (EV fire image)

## How to view

1. Clone or download the repo
2. Place the three image files next to `index.html`
3. Open `index.html` in a browser or deploy to any static host (GitHub Pages, Netlify, Vercel, etc.)
